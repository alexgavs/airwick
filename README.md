# airwick

ATtiny13 firmware that turns a battery-powered AirWick-style aerosol dispenser into a programmable timed sprayer with a single button and an LED.

## What it does

Single-source AVR firmware (`airwick.c` / `airwick.h`) for an ATtiny13 running at ~4.8 MHz / CKDIV8 (`F_CPU = 9600000 / 8 / 2`, fuses `LFUSE=0x69`, `HFUSE=0xFF`).

- A push button (PB1, INT0) cycles through up to 5 timing modes; long-press enters programming mode and stores the selected mode in EEPROM.
- A short press fires a single "pshik" by toggling a gate transistor (PB2) for ~1 second and blinking the cathode LED (PB0).
- Includes optional light-sensor support (`USE_LIGHTSENSOR`), watchdog reset, sleep mode (`avr/sleep.h`) and EEPROM-persisted settings.
- Counters are placed in the `.noinit` SRAM section so they survive resets within a single power session.

Comments are in Russian; the original code reference is `http://pastebin.com/JLT2Gf7a`. Author: Grigoriev Alexander, 2013.

## Stack

- Language: C (avr-libc / avr-gcc).
- Target: Atmel ATtiny13.
- Toolchain: Atmel/Microchip Studio (`airwick.atsln` / `airwick.cproj`); the `Debug/` and `Release/` Makefiles are auto-generated by the IDE.

## Build / Run

- Open `airwick.atsln` in Atmel/Microchip Studio and build the `Debug` or `Release` configuration.
- Or build from the command line with avr-gcc by running `make` inside `Debug/` or `Release/` (Studio-generated Makefile, requires WinAVR/AVR-GCC tools on `PATH`).
- Flash the resulting `airwick.hex` to an ATtiny13 with the fuses listed above (e.g. `avrdude -p t13 -U flash:w:airwick.hex -U lfuse:w:0x69:m -U hfuse:w:0xFF:m`).

## Layout

- `airwick.c`, `airwick.h` — firmware sources.
- `airwick.atsln`, `airwick.cproj`, `airwick.atsuo` — Atmel Studio project files.
- `Debug/`, `Release/` — generated build outputs (`.hex`, `.elf`, `.eep`, `.lss`, `.map`, `.srec`).
- `AirWick.attiny13.ZIP`, `airwick_delay_light.rar` — older snapshots/variants of the project.
